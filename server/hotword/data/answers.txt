# 「热词」答案池
#
# 一行一个：<词> <类别>。# 开头是注释。
# 类别只用在提示上——猜够次数以后会告诉双方"这个词属于 食物"。
#
# 挑词的三条规矩（改这个文件时照着来）：
#   1. 具体名词。"原则""指数""理论"这种抽象词没人猜得到，别放。
#   2. 2-3 个字，日常口语里真的会说的。
#   3. 不要专有名词（人名、地名、品牌），朋友之间联想不到一块儿去。
#
# 改完必须跑一遍 node scripts/build-hotword-data.mjs <词向量路径>，
# 它会告诉你哪些词不在词表里——不在词表的答案会让那一局彻底无解。
